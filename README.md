# HUB MULTIA

Sistema central para coordinar proyectos y múltiples inteligencias artificiales.

## Propósito

Este repositorio funciona como memoria operacional compartida entre las distintas IA que participan en los proyectos.

## Principios

- La información importante debe quedar registrada.
- Los proyectos deben estar separados.
- Las decisiones deben conservar su historial.
- Las IA deben poder consultar y modificar información de manera controlada.
- GitHub conserva las versiones y la evolución del sistema.

- Las 7 Leyes
- El Argento
- Otros proyectos futuros
